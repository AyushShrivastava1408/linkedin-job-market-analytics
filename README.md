# LinkedIn Job Market Analytics Dashboard

## Project Overview
Analysis of LinkedIn job market trends using SQL, Python, and Power BI.

## Tools Used
- Python
- SQL
- Power BI
- Pandas
- MySQL

## Features
- Job trend analysis
- Skills demand analysis
- Country-wise hiring insights
- Interactive Power BI dashboard

## Key Insights
